搭建一个静态博客网站 ​

搭建自己的静态博客，是我这段时间做得比较完整的一件事。这篇文章记录我所用的工具、搭建博客的原因，以及从寻找设计参考到上线发布的整个过程。

1. 需要的工具 ​

  1. GitHub 账号
  2. VPN 工具
  3. 好用的 Agent 工具，这里推荐 DeepSeek Harness

2. 为什么我想搭建个人博客 ​

从就业的角度来看，个人博客相比普通简历能够更好地展示自己的优势，也更容易一下子抓住面试官的眼球。

当然，更主要的原因是，我认为做网站十分有趣。可以在网络上拥有一个属于自己的私人空间，在上面发发牢骚，最重要的是能够记录自己成长的历程和所思所想。

3. 如何制作一个个人博客 ​

对于个人网站，我认为对新手来说最重要的是模板和 UI 选择，也就是整个网站的设计。

作为一个新手，我们往往没有什么灵感，这时候可以从模仿开始，走前人已经走过的路。以下是我常用的灵感搜集网站：

  • Huemint 配色
  • v0 模板库
  • Figma 社区

我们可以在这些网站中搜索关键词 “portfolio”，找到设计师们优秀的作品。学习他们的灵感之后，再把这些设计融入自己的博客制作中。

第二个推荐是经过市场验证的配色方案页面。你可以不断筛选，找到自己喜欢的颜色搭配，再应用到个人博客中。

之后在 GitHub 上创建一个个人博客仓库。每实现一个功能、修复一个 bug，就把改动提交到仓库中。

4. 如何在不使用服务器的情况下让别人看到网站 ​

我们把做完的前端页面源代码打包，然后发布到另一个仓库，利用 GitHub Pages 免费托管，就可以让别人访问我们的博客。

整个网站不需要后端、数据库或服务器运行时，维护成本很低。

5. 后续打算 ​

我会在有一定经济条件的情况下，选择租借一台云服务器，把这个项目不断完善，并加入后端功能，使它逐渐成长为一个完整的全栈项目。

谢谢你的阅读。
